## 🏛️ Overview
This is the official international-standard portfolio website for the **Iqbal Study Centre (ISC)**, headquartered at Banasree, Dhaka, Bangladesh. Developed directly from the 41-page institutional charter and strategic roadmap (2026–2029).

### ✨ Key Architecture & Features
- **Imperial Aesthetic:** Deep Cosmic Obsidian (`#040812`), Midnight Sapphire (`#0A1120`), Handcrafted Gold Leaf (`#D4AF37`, `#FEF08A`), and Persian Turquoise (`#0D9488`, `#2DD4BF`).
- **Premium Silk Preloader:**
  - SVG Circular Dashoffset Ring animation
  - Central rotating Allama Iqbal Medallion with glowing breathing aura
  - Real-time numerical progress counter (00% to 100%)
  - Rotating bilingual Iqbal aphorisms with smooth typography crossfades
  - Curtain raise entrance reveal
- **Multi-Page & Deep Routing:**
  - `index.html`: Flagship full interactive single-page application with hash-based deep linking
  - `about.html`: Philosophical masterclass on Allama Muhammad Iqbal (Sialkot to Munich), Khudi, Bekhudi, Harakat, Ijtihad, and canonical works
  - `activities.html`: Documented evidence archive featuring all extracted high-resolution event photographs, keynote speeches, prize laureates, and verified national press links
  - `leadership.html`: Complete directory of the 9 Advisory Council scholars, 12 Central Executive Council officers, and 26 General Assembly fellows with live search and filter
  - `roadmap.html`: Four-year strategic roadmap (2026–2029) detailed phase by phase plus operational requirements (human resources, physical infrastructure, digital media kits)
  - `budget.html`: Interactive Financial Plan Explorer with real-time multi-currency converter (BDT, USD, EUR, GBP, PKR) covering Phase I, Phase II, and Phase III Dhanmondi capital expenditure
  - `contact.html`: Institutional partnership and student fellowship portal
- **Motion & Visual Polish:**
  - Interactive HTML5 celestial particle canvas (stardust nodes responding to cursor)
  - 3D card tilt perspective interactions
  - Luxury custom cursor with trailing stardust ring
  - Built-in meditative ambient audio synthesizer (Web Audio API Sufi modal drone in D-minor)
  - Modal photo lightbox for full-screen inspection of documented event pictures
  - Real-time dynamic search and category filtering

## 🚀 How to Run & View
You can view the site immediately using either of the following methods:

### Method 1: Local Server (Running on Port 8000)
Open in your browser:
**`http://localhost:8000/`**

### Method 2: Direct File Open
Double-click `index.html` or open directly in any browser:
**`file:///Users/user/.gemini/antigravity/scratch/iqbal-study-centre/index.html`**
